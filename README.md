# Ben Davidian

Software Engineer · B.Sc. Computer Science, Bar-Ilan University
Backend, Systems and Applied ML. Looking for a full time role.

## Featured projects

**[Kesher AI](https://github.com/Bendavidian/Kesher-AI)** · [live demo](https://kesher-5ymr.onrender.com)
Real time market intelligence that maps news and SEC filings to each investor's holdings and explains why every event reached them.

**[GlassBox Trader](https://github.com/Bendavidian/glassbox-final-project)**
Explainable algorithmic paper trading system, with exact attribution derived from the models' weights, and a study run on it.

**[YouTube-style Video Sharing Platform](https://github.com/Bendavidian/YouTube_Project)**
Full stack video sharing platform with FFmpeg thumbnails, dual token JWT auth and a multi threaded TCP service.

**[Yakarly](https://github.com/Bendavidian/yakarly)** 
Conversational fee analysis and lead engine that answers with a priced verdict instead of a callback.
